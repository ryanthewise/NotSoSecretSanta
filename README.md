### Secret Santa Organizer
This Python program is a Secret Santa organizer that allows you to manage your Secret Santa event, shuffle participants, and send assignment emails. It uses the Tkinter library for the graphical user interface (GUI) and allows you to add both adults and children as participants.

## Features
* Add Participants: You can add adults and children by providing their names and email addresses (for adults). The program ensures that no participant is left empty-handed.

* Shuffle Participants: With the click of a button, you can shuffle the participants to create Secret Santa pairings. The program will randomly assign adults to each other and pair children with selected adults.

* Email Notifications: You can send email notifications to participants directly from the program. It provides options to send emails to all participants or individual participants.

* Customizable Email Messages: The program generates personalized email messages for each participant, including their assigned Secret Santa recipient's name and other event details.

## Usage
* Add participants by entering their names and email addresses (for adults) or just their names (for children).

* Click the "Add Adult" or "Add Child" button to add participants.

* Once all participants are added, click the "Shuffle" button to create Secret Santa pairings.

* Use the "Email Direct" button to send assignment emails to individual participants.

* Use the "Email All" button to send assignment emails to all participants.
